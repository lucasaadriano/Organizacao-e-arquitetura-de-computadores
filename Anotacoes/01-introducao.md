
# 1. Introdução à Organização e Arquitetura de Computadores

## O que é?

Organização e Arquitetura de Computadores é a área que estuda como os computadores são estruturados, como seus componentes funcionam e como eles trabalham juntos para executar programas.

## Arquitetura de computadores

A arquitetura está relacionada às características de um computador que são relevantes para o funcionamento dos programas, como:

- Conjunto de instruções que o processador executa;
- Tipos de dados suportados;
- Formas de acessar a memória;
- Modos de endereçamento.

## Organização de computadores

A organização está relacionada à maneira como os componentes internos são implementados e conectados para realizar as funções definidas pela arquitetura.

Exemplos:

- Organização das unidades internas do processador;
- Funcionamento dos barramentos;
- Implementação da memória cache;
- Conexão entre processador e memória.

## Diferença entre arquitetura e organização

A arquitetura define principalmente o que o computador oferece ao programador, enquanto a organização trata de como os componentes são estruturados para implementar essas funcionalidades.

## Resumo

A arquitetura descreve as características funcionais do computador, enquanto a organização explica como seus componentes são implementados e trabalham juntos.
