
# 5. Memória Principal e Memória Secundária

## Memória principal

A memória principal é utilizada para manter dados e instruções necessários ao funcionamento dos programas.

### RAM

RAM significa *Random Access Memory*.

É utilizada para armazenar temporariamente informações em uso. Na memória RAM convencional dos computadores, os dados são perdidos quando a alimentação elétrica é interrompida.

## Memória secundária

É utilizada para armazenar programas, arquivos e dados por períodos prolongados, mesmo quando o computador está desligado.

Exemplos:

- SSD;
- HD;
- Pen drive;
- Cartão de memória.

## Diferenças entre RAM e armazenamento

| Característica | RAM | SSD ou HD |
|---|---|---|
| Função principal | Manter dados em uso | Guardar arquivos e programas |
| Persistência sem energia | Normalmente não | Sim |
| Uso | Acesso temporário pelo sistema e programas | Armazenamento de longo prazo |
| Capacidade | Geralmente menor | Geralmente maior |

## Hierarquia de memória

Os computadores utilizam diferentes níveis de armazenamento porque é difícil ter uma memória que seja simultaneamente muito rápida, muito grande e barata.

Uma visão simplificada da hierarquia é:

1. Registradores;
2. Memória cache;
3. Memória RAM;
4. Armazenamento secundário.

Em geral, os níveis mais próximos do processador são mais rápidos, menores e mais caros por unidade de capacidade.

## Resumo

A RAM mantém informações utilizadas durante a execução dos programas. SSDs e HDs armazenam dados de forma persistente. A hierarquia de memória busca equilibrar velocidade, capacidade e custo.
