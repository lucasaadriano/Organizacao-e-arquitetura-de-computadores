
# 2. Estrutura do Computador

Um computador é formado por diferentes componentes que trabalham juntos para receber dados, processar informações, armazenar resultados e apresentar respostas ao usuário.

## Principais componentes

### 1. Processador (CPU)

É responsável por executar instruções e coordenar as operações do computador.

### 2. Memória principal (RAM)

Armazena temporariamente os dados e as instruções que estão sendo utilizados pelo sistema.

### 3. Armazenamento secundário

Guarda arquivos, programas e outros dados mesmo quando o computador é desligado.

Exemplos: SSD e HD.

### 4. Dispositivos de entrada

Permitem inserir dados no computador.

Exemplos: teclado, mouse e microfone.

### 5. Dispositivos de saída

Permitem apresentar os resultados do processamento.

Exemplos: monitor, impressora e alto-falantes.

### 6. Barramentos

São caminhos de comunicação utilizados para transportar dados, endereços e sinais de controle entre os componentes.

## Como os componentes trabalham juntos?

Ao abrir um programa, o sistema pode carregar suas instruções e seus dados do armazenamento para a memória RAM. O processador busca as instruções, executa as operações necessárias e produz resultados que podem ser apresentados na tela ou armazenados.

## Resumo

O computador funciona por meio da integração entre processador, memória, armazenamento, dispositivos de entrada e saída e mecanismos de comunicação.
