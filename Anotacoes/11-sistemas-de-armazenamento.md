
# 11. Sistemas de Armazenamento

## O que são?

Sistemas de armazenamento são utilizados para guardar dados e permitir que sejam recuperados posteriormente.

Eles podem armazenar arquivos, programas, documentos, imagens, vídeos e informações utilizadas por sistemas computacionais.

## Principais tecnologias

### HD (Hard Disk Drive)

Utiliza discos magnéticos e componentes mecânicos para armazenar e acessar dados.

### SSD (Solid State Drive)

Utiliza memória não volátil, normalmente baseada em flash, e não possui as partes mecânicas de um HD.

### Pen drive e cartão de memória

Também utilizam memória flash para armazenar dados.

## RAID

RAID significa *Redundant Array of Independent Disks*. É uma técnica que combina várias unidades de armazenamento para alcançar objetivos como desempenho, redundância ou ambos, dependendo da configuração.

### RAID 0

Distribui dados entre duas ou mais unidades para melhorar o desempenho. Não oferece redundância: a falha de uma unidade pode comprometer o conjunto.

### RAID 1

Mantém cópias espelhadas dos dados em unidades diferentes. Pode continuar funcionando após a falha de uma unidade, dependendo da configuração e do estado do conjunto.

### RAID 5

Distribui dados e informações de paridade entre pelo menos três unidades. Pode tolerar a falha de uma unidade.

### RAID 6

Distribui dados e dupla paridade entre pelo menos quatro unidades. Pode tolerar a falha de até duas unidades.

## RAID não é backup

RAID pode ajudar a manter a disponibilidade dos dados diante de certas falhas de unidades, mas não substitui um backup.

Apagamentos acidentais, corrupção de arquivos, ataques e outros problemas podem afetar os dados mesmo em um sistema RAID.

## Resumo

As tecnologias de armazenamento apresentam diferenças de velocidade, capacidade e custo. O RAID combina unidades para oferecer características específicas, mas deve ser acompanhado de uma estratégia de backup.
